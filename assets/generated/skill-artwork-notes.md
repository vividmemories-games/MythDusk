# Skill artwork for all five heroes

Generated with built-in imagegen, using the previous Knight skill illustration as a style reference. Five transparent 2×2 icon atlases are optimized to 800×800 WebP in assets/images/skills/. Each stable skill ID maps to an atlas cell in lib/core/assets/skill_artwork.dart; lib/core/widgets/skill_art.dart renders that cell and supplies a visible fallback for unknown IDs or failed loads. The briefing continues to use profile.combatHero() and displays only its equipped skills in their saved order. Skills, costs, mastery gates and the two-skill loadout rule are unchanged.

The old two-icon reference is archived as assets/generated/knight-skills-reference.webp and is no longer bundled.
