# Home and pre-battle runtime artwork

Generated with the built-in imagegen tool using the approved Home v2 and pre-battle v3 concepts as style references. Decorative assets contain no UI labels. Flutter renders live text, semantic controls, profile state and routes separately. Source images remain in Codex generated-images storage; optimized WebP outputs are bundled in assets/images/home/. Existing challenge frames, gold button, seals, and bog scenery are reused.

## courtyard.webp

Use case: stylized-concept. Create a text-free reusable background asset for MythDusk mobile Home. Reference image is style reference only. Recreate its painterly moonlit medieval castle courtyard: crescent moon upper left, distant gothic castle with warm windows upper right, ivy-covered stone arches and columns framing both sides, sparse warm lanterns, teal mist and blue midnight sky. Lower central area has weathered courtyard paving. Empty central foreground for an independently rendered hero. No characters, no UI, no text, no buttons, no frames, no coins, no logos. Portrait aspect matching reference. A small low engraved circular mossy stone dais with restrained cyan runes centered about 60% down the image, large enough to host a chibi hero. Atmospheric beautiful handcrafted RPG painting, keep central area clear and readable.

NO characters, NO swords in foreground, NO text, NO labels, NO UI, NO button, NO border/frame, no watermark. Match reference's 1v1 crimson arena environment only.

## dais.webp

Use case: background-extraction. Asset: transparent reusable stone hero dais sprite for MythDusk Home. Reference is visual style only. Isolated low circular ancient stone platform viewed from slightly above at 3/4 game scene angle, wide ellipse, weathered engraved stone slabs, moss along edges, restrained small glowing cyan runes along outer rim, antique gold etched concentric circle on top. Platform only, NO hero, no scene/background, no UI, no text. Painterly medieval fantasy RPG illustration matching reference courtyard. Entire platform visible, transparent background, landscape 2.5:1 framing with minimal margins. Solid tactile stone thickness and subtle contact shadow. Not a flat cyan oval.
